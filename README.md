# AI CEO: 인간과 알고리즘 사이

AI 비서와 인간 직원의 조언 사이에서 회사를 성장시키는 선택 중심 경영 시뮬레이션 게임입니다.

플레이어는 자본금 200만 원으로 작은 게임 회사를 시작합니다. 좋은 선택만 하면 되는 게임이 아닙니다. AI를 활용하면 빠르게 성장할 수 있지만 의존도가 높아지고, 인간의 판단을 고집하면 통제권은 지킬 수 있어도 경쟁에서 뒤처질 수 있습니다.

## 플레이 링크

**https://llaudeer.github.io/ai-ceo-visual-novel/**

로그인·설치·별도 승인 없이 바로 플레이됩니다. GitHub Pages로 배포되며, 저장소는 `llaudeer/ai-ceo-visual-novel` (공개)입니다.

## 프로젝트 상태

- 현재 목표: 오픈AI 게임 대회 제출용 브라우저 데모
- 개발 형태: 별도 설치 없이 실행되는 웹 빌드
- 예상 데모 플레이 시간: 10~15분
- 정식 버전: 데모 검증 후 확장
- 현재 문서의 기준일: 2026-08-06

## 대회용 데모와 정식 버전

| 구분 | 대회용 데모 | 정식 출시 버전 |
| --- | --- | --- |
| 목적 | 핵심 재미와 메시지를 짧게 전달 | 반복 플레이와 깊은 경영 경험 제공 |
| 플레이 시간 | 10~15분, 최대 20분 | 1회 1~3시간 또는 여러 세션 |
| 콘텐츠 | 압축된 1개 회사 이야기와 주요 엔딩 | 여러 회사 유형, 사건, 캠페인, 엔딩 |
| 시스템 | 핵심 자원, 직원, AI 조언, 버그, 결말 | 채용, 재무, 제품, 시장, 조직문화, 장기 리스크 |
| 기술 우선순위 | 안정적인 단일 웹 빌드 | 저장, 분석, 콘텐츠 확장, 배포 운영 |

데모에서 구현되지 않은 정식 버전 기능을 현재 기능처럼 설명하지 않습니다. 심사 링크에서 가장 중요한 것은 설치나 로그인 없이 바로 플레이되는 안정적인 핵심 루프입니다.

## 빠른 실행 안내

데모는 `index.html` 단일 파일입니다. 빌드 도구, 설치, 로그인, 네트워크 연결이 필요하지 않습니다.

```bash
open index.html
```

파일을 브라우저 창에 끌어다 놓아도 동일하게 실행됩니다. 배포 시에는 이 파일 하나만 정적 호스팅에 올리면 됩니다.

권장 플레이 안내:

1. 데스크톱 브라우저에서 `index.html`(또는 배포 링크)을 엽니다.
2. 로그인이나 설치 없이 `게임 시작`을 누릅니다.
3. 화면을 클릭하거나 `Space`로 대사를 넘깁니다. 타이핑 중에 누르면 즉시 전부 표시됩니다.
4. 직원과 AI 비서의 조언을 들은 뒤 선택지를 고릅니다(숫자 키 `1~3` 또는 클릭).
5. 회사 자금, 신뢰, AI 의존도, 직원 사기 변화를 확인합니다.
6. 버그와 위기 이벤트에 대응한 뒤 엔딩을 확인합니다.

화면의 조명 색은 `AI 의존도`를 따라 호박색에서 보라색으로 변합니다. 상태를 숫자뿐 아니라 화면 전체로 읽을 수 있게 한 장치입니다.

| 외부 의존 | 없음 (폰트·이미지·오디오 파일·API 호출 모두 사용하지 않음) |

## 다른 AI 에이전트가 작업할 때

새 에이전트는 다음 순서로 문서를 읽습니다.

1. `PROJECT_BIBLE.md`: 프로젝트의 기준과 절대 변경하면 안 되는 방향
2. `ROADMAP.md`: 현재 단계와 이후 단계
3. `TODO.md`: 당장 작업할 항목
4. 관련 `docs/*.md`: 수정하려는 시스템의 상세 규칙
5. `CHANGELOG.md`: 최근 변경사항과 알려진 결정

문서의 내용이 코드보다 오래되었다고 판단되면 임의로 무시하지 말고, 구현 상태를 확인한 뒤 변경사항을 `CHANGELOG.md`에 기록합니다.
