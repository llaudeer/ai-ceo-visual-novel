# ARIA : 7 WEEKS

3078년. 자금 100,000 CR. 남은 시간 7주.

작은 게임 회사 TRIPLEDOT STUDIO의 대표가 되어 `NEON MEMORY`를 출시해야 합니다. AI 비서 ARIA는 언제나 더 빠른 답을 알고 있고, 다섯 명의 사람은 더 느리지만 이유를 설명할 수 있습니다. 매주 결정을 내리고, 그 결정이 자금·팀 신뢰·품질·AI 의존도를 바꾸고, 7주 뒤 다섯 개의 엔딩 중 하나로 이어집니다.

3D 사무실을 직접 걸어다니면서 드라마가 진행되는 형식입니다.

## 플레이 링크

**https://llaudeer.github.io/ai-ceo-visual-novel/**

로그인·설치·별도 승인 없이 브라우저에서 바로 플레이됩니다. GitHub Pages로 배포되며, 저장소는 `llaudeer/ai-ceo-visual-novel` (공개)입니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| `W` `A` `S` `D` | 사무실 이동 (대사 진행 중에도 자유롭게 걸어다닐 수 있습니다) |
| 클릭 또는 `Space` | 대사 진행. 타이핑 중에 누르면 즉시 전부 표시됩니다 |
| `1` `2` `3` | 선택지 고르기 (클릭도 됩니다) |

## 로컬에서 실행

**`index.html`을 파일로 직접 열면 실행되지 않습니다.** ES module과 `importmap`을 사용하므로 `file://`에서는 브라우저 CORS 정책에 막힙니다. 정적 서버가 필요합니다.

```bash
python3 -m http.server 5173
```

그다음 브라우저에서 `http://localhost:5173` 을 엽니다.

three.js는 `vendor/three.module.js`에 저장소 안으로 포함되어 있습니다. CDN이나 네트워크 연결에 의존하지 않으므로, 위 서버만 뜨면 오프라인에서도 동작합니다.

## 테스트

```bash
node --test
```

상태 전이, 스토리 데이터 정합성, 충돌 판정, 레이아웃을 검증합니다. 스토리 테스트는 **모든 선택지 조합(13,122가지)을 실제로 완주시켜** 진행이 막히는 경로가 없고 다섯 엔딩이 전부 도달 가능한지 확인합니다.

## 게임 구성

| 항목 | 내용 |
| --- | --- |
| 형식 | 3D 사무실 + 선택 중심 경영 시뮬레이션 |
| 등장인물 | 5명 (이서연·정유나·최민·박지훈·한도윤) + AI 비서 ARIA |
| 진행 | 프롤로그 + WEEK 1~7 + 출시 |
| 결정 | 9개 (모두 상태값에 영향) |
| 엔딩 | 5종 |
| 플레이 시간 | 약 10~15분 |
| 외부 의존 | 없음 (CDN·API·폰트 파일·오디오 모두 사용하지 않음) |

### 상태값

| 값 | 시작 | 의미 |
| --- | --- | --- |
| `funds` | 100,000 CR | 주당 12,000~14,000 CR씩 빠져나갑니다. 0 이하면 즉시 폐업 |
| `trust` | 50 | 팀 신뢰. 사람의 판단을 택할수록 오릅니다 |
| `quality` | 50 | 게임 품질. 출시 성적을 가릅니다 |
| `aiDependence` | 0 | AI 의존도. ARIA에게 맡길수록 오릅니다 |

화면에 상시 노출되는 것은 자금과 AI 의존도 둘뿐입니다. 나머지는 결과로 체감하도록 숨겨 둡니다.

### 엔딩 판정

위에서부터 첫 번째로 맞는 것이 나옵니다. 순서 자체가 규칙입니다.

| 순서 | 엔딩 | 조건 |
| --- | --- | --- |
| 1 | `ZERO CR` | `funds <= 0` |
| 2 | `CORRUPTED` | 방치한 치명적 버그 2개 이상 |
| 3 | `PERFECT MACHINE` | `aiDependence >= 80` |
| 4 | `ONE MORE GAME` | `trust >= 70 && quality < 70` |
| 5 | `NEON STAR` | 그 외 전부 (폴백) |

ARIA 홀로그램의 색은 상황에 따라 바뀝니다. 보라(평상시) → 초록(제안) → 파랑(추천) → 빨강(경고). 숫자를 읽지 않아도 ARIA가 지금 무엇을 밀고 있는지 화면 전체로 보이게 하려는 장치입니다.

## 구조

```
index.html              부트스트랩, 타이틀 화면, importmap
vendor/three.module.js  three.js r169 (저장소 포함, CDN 미사용)
src/
  main.js               3D 월드와 스토리를 연결하는 유일한 지점
  game/
    story.data.js       대본 전체. 통째로 교체 가능
    state.js            상태값과 순수 전이 함수
    flow.js             진행 상태 기계 (three.js도 DOM도 모름)
    characters.data.js  캐릭터 정본 데이터와 사무실 좌석 좌표
  ui/
    hud.js              대사창·선택지·스탯·엔딩 (DOM 레이어)
    theme.js            ARIA 4상태 컬러 토큰
  world/                3D 씬 — 사무실, 조명, 백드롭, 빌보드, ARIA 홀로그램
  player/               이동, 충돌, 추적 카메라
test/                   node:test
legacy/                 2D SVG 비주얼 노벨 (이전 판, 보존용)
```

의존 방향은 한쪽입니다. `game/`은 three.js와 DOM을 모르고, `world/`는 스토리를 모릅니다. `main.js`만 양쪽을 압니다.

## 다른 AI 에이전트가 작업할 때

1. `PROJECT_BIBLE.md`: 프로젝트의 기준과 절대 변경하면 안 되는 방향
2. `docs/GAMEPLAY.md`: 숫자, 밸런스, 엔딩 판정의 근거
3. `ROADMAP.md` / `TODO.md`: 현재 단계와 작업 목록
4. `CHANGELOG.md`: 최근 변경사항과 알려진 결정

문서가 코드보다 오래되었다고 판단되면 임의로 무시하지 말고, 구현 상태를 확인한 뒤 변경사항을 `CHANGELOG.md`에 기록합니다.
